# 项目页面:大语言模型的因果识别能力

两个实证研究:**因果形式化高分的解释边界**,以及**因果假设变化下的识别状态更新**。

---

## 一句话概述

我完成了两个面向"大语言模型能否进行因果推理"的实证研究。**第一篇**追问"高分能说明什么":在二值工具变量、以顺从者平均处理效应为目标的因果部分识别任务上,构造了一个只做模板选择与字段转录、不对任何实例值做算术、也不调用优化器的受限程序,它在 233 条评分样本上取得与微调模型相同的 233/233 满分,并给出了该类程序成功与否的精确数学条件,从而说明这个分数无法区分"一般因果形式化能力"与"族内模板路由",同时证明打败一个受限实现并不等于排除邻近实现。**第二篇**追问"假设变化时能否正确更新":在观测证据与因果目标固定、仅增加一条结果单调性假设的配对设置下,用 LoRA 微调三个种子的适配器,在 120 个全新实例(20 个评测格、19,200 次生成)上做前瞻性确认,并用 B/Q/U 分解把"原题是否答对"与"新假设下是否正确应用"分开——熟悉表述下准确率为 91.8%–94.3%,但变化题对两侧同时正确的比例接近零;换成更完整的任务说明后配对成功率显著提升(ΔU = +0.121,95% 实例聚类区间 [+0.104, +0.137]),代价是原题准确率降到 40.0%–49.8%。

---

## 核心结果

### 项目一:这个分数能说明什么

| 系统 | 判据 | 成绩 |
|---|---|---:|
| 微调模型 | 变量集 + 约束集 RREF + 目标 | 233/233 |
| **模板—路由程序(不做算术)** | 同一判据 | **233/233** |
| 打乱配对负对照 | 同一判据 | 0/233 |
| 伴随搜索探针 | 两端点最优 | 2/233 |

目标里每个实例特定数值都能在题目中**原样找到**,整批题目的结构差异只有**一个比特**。
因此这个分数无法区分"一般因果形式化"与"族内模板选择 + 字段转录"。

### 项目二:假设变化时能否正确更新

120 个全新实例 × 8 个假设子集 × 2 个开关设置 → 20 个评测格、19,200 次生成,**零新增训练**。

| 条件 | 种子 27 | 种子 28 | 种子 29 |
|---|---:|---:|---:|
| 历史规格 · 不施加限制 (O-F) | 905 / 960 | 893 / 960 | 881 / 960 |
| 历史规格 · 施加限制 (O-T) | 426 / 960 | 402 / 960 | 366 / 960 |
| 完整规格 · 显式 false (N-F) | 384 / 960 | 478 / 960 | 443 / 960 |
| 完整规格 · 显式 true (N-T) | 335 / 960 | 349 / 960 | 521 / 960 |

在标准答案真正改变的 **470 个题对**上:

- `B`(原题正确率)= 0.934 / 0.953 / 0.945
- `Q`(原题答对后新题也对的比例)= 0 / 0 / 0.011
- `U`(两侧同时正确率)= **0 / 0 / 5** of 470

换成完整规格后 `ΔU = +0.1206`,95% 实例聚类区间 `[+0.1040, +0.1372]`;
但全 960 题准确率降到 **40.0%–49.8%**,且没有一个种子达到预设的 `U ≥ 0.60`。

## 适用范围与边界

- 单一模型家族(Qwen2.5-7B-Instruct)、一种训练配置、**三个**冻结训练运行、**一条**新增结构假设。
- 评测分布是预定义等权分层,不是自然总体分布;区间**条件于这三个训练运行**,不代表训练随机性的总体区间。
- 完整规格对只在历史规格上训练过的适配器属于**分布外格式**,其效应**不能**拆分归因于内容、长度或格式中的某一项。
- 历史提示未显式固定参照区间,因此低配对成功率**不能**升级为"模型不理解该新增假设"。
- 一切结论停在**输出行为**层面;数值端点始终由程序计算,模型只输出类别。
- "存在一个简单实现也拿高分"只说明该替代实现存在,**不说明模型使用了它**。
